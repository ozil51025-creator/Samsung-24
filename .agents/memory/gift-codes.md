---
name: Gift-code issuance
description: Product rule for who creates gift codes and which controls admins set.
---

Gift codes must be created manually by an administrator. The administrator chooses the code, wallet-credit amount, maximum redemptions, and optional expiration; admins can disable codes.

**Why:** the user asked for gift codes to be managed manually by an admin.

**How to apply:** Keep code issuance in the authenticated admin panel; do not auto-generate or auto-issue codes.
